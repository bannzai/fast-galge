# 方向性: fast-galge

## 仮説

ノベルゲーム・ギャルゲーの定番の演出を知っている人は、文字送りが止められないほど速く、選択肢に 2 秒の制限時間があるギャルゲーを「変なゲーム」として笑い、5 分で遊び切って人に共有する。速さ以外 (立ち絵・背景・好感度・分岐・複数エンディング・バックログ・セーブ) を普通のギャルゲーの水準で揃えることで、「速いだけのネタ」ではなく「ちゃんとしたギャルゲーが速い」というずれが面白さになる。

## 判定基準

公開前は関門 3 (触れる版) で bannzai 本人が「速い会話が面白いか、それ以外はちゃんとギャルゲーか」を判断する。公開後は 14 日ごとに下の表で判定する。

| 指標 | 計測元 (skill / コマンド) | 継続のしきい値 | 打ち切り条件 | 転換の条件 |
| --- | --- | --- | --- | --- |
| 直近 7 日のゲームページの訪問数 | Cloudflare Web Analytics の訪問数を `/cloudflare-web-analytics-report --site bannzai.github.io` で取得 (JS スニペットは fast-galge のページだけに置く) | >= 30 | < 10 x2 (2 回連続) | 訪問は 30 以上だがエンディング到達率が 20% 未満なら、速度の調整 (ゆっくりモードの既定化) か 1 ルートの短縮に転換 |
| 直近 7 日のエンディング到達率 (`/fast-galge/ending/*` の PV ÷ `/fast-galge/` の PV) | 同上 (エンディング表示時に `history.pushState` で `/fast-galge/ending/<id>` へ移り、スニペットの SPA 計測で PV を送る) | >= 20% | < 5% x2 | 到達率は高いが訪問が増えないなら、SNS で共有しやすい結果画面 (エンディング名と所要時間の画像) に転換 |

## 必要な機能

関門 1 (構想) で bannzai が過不足を判断する一覧。

- [ ] 高速会話: 文字送りが自動で進み止められない (1 メッセージ 0.4〜0.8 秒。文字数で変える)。選択肢は制限時間 2 秒で、時間切れは「……」(無言) を選んだ扱いになり好感度が下がる
- [ ] シナリオと分岐: ヒロイン 2 人、各ルート 5 分前後。好感度で good / bad の 2 エンディングずつと、共通の bad エンディング 1 つ。シナリオは agent が書く
- [ ] ギャルゲーの基本演出: 背景・立ち絵 (表情差分)・名前つきメッセージウィンドウ・BGM と効果音・場面転換
- [ ] バックログ: 流れた会話をいつでも読み返せる (速さの救済。開いている間は会話が止まる)
- [ ] セーブ・ロード: 章の区切りでのオートセーブと、タイトルからの「つづきから」。ブラウザのローカル保存 (`user://`)
- [ ] エンディング一覧と周回: 見たエンディングの一覧、クリア後に「ゆっくりモード」(通常の速さ) を解放
- [ ] タイトル・設定・クレジット: 音量、素材のクレジット、利用規約・プライバシーポリシーへのリンク
- [ ] Web エクスポートと配信: GitHub Pages で `https://bannzai.github.io/fast-galge/` に公開。計測は Cloudflare Web Analytics の JS スニペット (関門 3 の後に有効にする)
- [ ] 検証の仕組み: headless のロジック検証・入力統合テスト、CI での撮影と録画 (ローカル Mac で Godot を動かさない)

入れていないもの: 課金、アカウント、サーバー、多言語 (日本語のみ)、ボイス、Steam・ストア配信、スマホアプリ。

## agent に任せること

- 配信先: GitHub Pages (`docs/` の LP と法務ドキュメントに加え、関門 3 の後に Web ビルドを `docs/play/` へ CD で配置する)。itch.io への同時配信は後で判断する
- 計測: Cloudflare Web Analytics の JS スニペット (Cloudflare 外のサイト向け)。サイトの追加は設定済みの API トークンで `POST /accounts/{account_id}/rum/site_info` を呼ぶ
- DB・認証・課金は持たない。保存はブラウザのローカル保存だけ
- ビルド・テスト・画面の確認は GitHub Actions の Linux ランナーで行い、ローカル Mac で Godot を動かさない。Web ビルドの操作を伴う確認は webtunnel (runner 上の Chromium) で行う
- 利用規約・プライバシーポリシーは GitHub Pages のページ。課金が無いため特定商取引法に基づく表記は作らない
- 速度の具体値 (1 メッセージの表示時間・選択肢の制限時間) は実装しながら CI の録画で見て決める
