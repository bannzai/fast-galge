# プライバシーポリシー

bannzai（以下「提供者」といいます。）は、提供者が提供するゲーム「fast-galge」（以下「本ゲーム」といいます。）における、ユーザーについての個人情報を含む利用者情報の取扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます。）を定めます。

## 収集する利用者情報および収集方法

本ポリシーにおいて、「利用者情報」とは、ユーザーの識別に係る情報、通信サービス上の行動履歴、その他ユーザーまたはユーザーの端末に関連して生成または蓄積された情報であって、本ポリシーに基づき提供者が収集するものを意味するものとします。

### ゲームのデータ（端末内にのみ保存されます）

本ゲームの進行状況や設定などのデータは、**ユーザーの端末内にのみ保存され、提供者のサーバーに送信されません**。本ゲームは提供者のサーバーと通信せず、アカウント登録を必要としません。広告は表示せず、利用状況を分析するための外部サービス（アクセス解析・クラッシュ収集等）を組み込んでいません。

エンディングの結果画面には、結果の画像（エンディング名・所要時間・選んだ選択肢の数・時間切れの回数）と投稿用の文面を X（X Corp. が運営する SNS）へ共有する機能があります。ユーザーが共有の操作をした時にだけ、文面を含めた X の投稿画面の URL（ https://x.com/intent/post ）を端末の既定のアプリ（ブラウザまたは X のアプリ）で開き、投稿するかどうかはユーザー自身が X の画面で決めます。結果の画像はユーザーの端末内に保存され（PC 版は OS のピクチャフォルダ。Linux で OS がピクチャフォルダを持たない時はホームフォルダ。フォルダが見つからない時はアプリの保存領域。保存した場所は共有の操作の後に画面に表示します）、投稿に添付するかどうかはユーザー自身が行います。iOS 版では結果の画像はアプリの保存領域に保存され、現在の版ではユーザーが直接取り出す手段はありません（投稿に添付する場合は端末のスクリーンショットをご利用ください）。PC 版では文面を端末のクリップボードにもコピーします。画像も文面も提供者のサーバーを経由しません。X への投稿に関する情報は X Corp. が取り扱い、同社のプライバシーポリシー（ https://x.com/privacy ）に従って管理されます。

### Steam が扱う情報

本ゲームの PC 版は Valve Corporation が運営する Steam を通じて配信します。Steam アカウント、および Steam の機能（ライブラリ、レビュー等）に関する情報は Valve Corporation が取り扱い、同社のプライバシーポリシー（ https://store.steampowered.com/privacy_agreement/ ）に従って管理されます。提供者が Steamworks を通じて参照できるのは、ダウンロード数・レビュー数などの個人を特定しない集計情報です。

### App Store が扱う情報

本ゲームの iOS 版は Apple Inc. が運営する App Store を通じて配信します。Apple ID、ダウンロード、およびレビューに関する情報は Apple Inc. が取り扱い、同社のプライバシーポリシー（ https://www.apple.com/legal/privacy/ ）に従って管理されます。提供者が App Store Connect を通じて参照できるのは、ダウンロード数・評価・レビューなどの個人を特定しない集計情報と、ユーザーが公開したレビューの内容です。

### 紹介ページの配信基盤（GitHub Pages）

本ページを含む紹介ページは GitHub, Inc. が提供する GitHub Pages で配信します。ページの配信にあたり、GitHub, Inc. がアクセス元の IP アドレス等をサーバーログとして取得することがあります。これらの情報は同社のプライバシーステートメント（ https://docs.github.com/ja/site-policy/privacy-policies/github-general-privacy-statement ）に従って取り扱われ、提供者は参照しません。

### 提供者が収集する情報

ユーザーがメール等で問い合わせを行った場合に限り、提供者はその連絡先と問い合わせ内容を取得します。

提供者は、ユーザーから、個人情報保護法の定めに基づき個人情報の開示・訂正・利用停止・消去を求められたときは、ユーザーご本人からのご請求であることを確認の上で、遅滞なく対応します（当該個人情報が存在しないときにはその旨を通知いたします。）。ただし、個人情報保護法その他の法令により提供者が義務を負わない場合は、この限りではありません。請求は下記のお問い合わせ窓口へメールでお送りください。

端末内にのみ保存されているゲームのデータは提供者が保有していないため、ユーザー自身が消去できます。iOS 版はアプリを削除すると、アプリの保存領域ごと消去されます。PC 版は本ゲームをアンインストールしても保存データのフォルダは残るため、次のフォルダを削除してください（Godot エンジンの保存先。 https://docs.godotengine.org/en/4.7/tutorials/io/data_paths.html ）。

- Windows: `%APPDATA%\Godot\app_userdata\fast-galge`
- macOS: `~/Library/Application Support/Godot/app_userdata/fast-galge`
- Linux: `~/.local/share/godot/app_userdata/fast-galge`

結果画面の共有で PC 版がピクチャフォルダ（またはホームフォルダ）に保存した結果の画像（`fast-galge-result.png`。共有のたびに同じ名前のファイルを上書きします）は、上記のフォルダには含まれないため、不要になったらユーザー自身が削除してください（フォルダが見つからずアプリの保存領域に保存された場合は上記のフォルダに含まれます）。
